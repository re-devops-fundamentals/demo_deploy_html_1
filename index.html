📌 Mẹo kiểm tra nhanh khi deploy lên VPS:

  • Nếu không truy cập được qua IP: Kiểm tra Security Group trên Cloud (AWS/DigitalOcean/Linode) và tường lửa ufw status.
  • Nếu gặp lỗi 403 Forbidden: Kiểm tra phân quyền file chmod 755 /var/www/html và file index.html.
  • Nếu Nginx không nhận thay đổi: Chạy sudo systemctl reload nginx.

⚙️ File Cấu Hình Nginx Mẫu

/etc/nginx/sites-available/default 
server {
    listen 80 default_server;
    listen [::]:80 default_server;

    root /var/www/html;
    index index.html index.htm;

    server_name _;

    location / {
        try_files $uri $uri/ =404;
    }

    # Cache file tĩnh để tối ưu hiệu năng
    location ~* \.(css|js|png|jpg|svg|ico)$ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }
}
